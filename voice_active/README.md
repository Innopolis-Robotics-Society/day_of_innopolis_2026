To run this script you need to:
1. install pixi enviroment
(install pixi on your computer: https://pixi.prefix.dev/latest/installation/ )
2. run *git clone* to a specific folder and *cd* there
3. run *pixi install* in terminal
4. install models for russian and english transcribtion from there:
https://alphacephei.com/vosk/models
and extract their content into **model_en** and **model_ru** folders
5. run the whole script by following command:
*pixi run python3 voice_activation.py*
